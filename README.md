# 随想

一个纯白、单栏的极简日记网页。默认没有账号、没有服务器、不联网，写下的文字只保存在你自己的浏览器里；需要的话，可以接入自己的 Supabase 项目，让手机和电脑自动同步。

## 打开方式

双击 `index.html`，用 Edge 或 Chrome 打开即可。

想随时写，可以右键 `index.html` →「发送到」→「桌面快捷方式」，把快捷方式放到桌面或任务栏。

## 怎么用

- 在顶部输入框里写，点「保存」或按 `Ctrl / Cmd + Enter`。
- 记录按天分组，最新的在最上面。
- 鼠标移到一条记录上，右上角会出现「编辑 / 删除」；手机上一直显示。
- 删除后 6 秒内可以点提示里的「撤销」恢复。
- 顶栏搜索会同时匹配正文和旧记录里的标签，命中处高亮。
- 没写完就关掉页面也没关系，内容会自动存成草稿，下次打开时恢复，可以点「丢弃」清空。

## 数据存在哪里

所有记录首先保存在浏览器的 **localStorage** 里；开启云同步后，会同时写入你自己的 Supabase 数据库：

- 记录：`suixiang.entries.v1`
- 草稿：`suixiang.draft.v1`

这意味着：

- 清理浏览器缓存 / 站点数据，记录会消失；
- 换浏览器、换电脑，记录不会自动跟过去；
- 无痕模式下关闭窗口，记录会被清掉；
- 移动 `index.html` 的位置或改名，少数浏览器可能读不到原来的数据。

所以：**请定期导出备份。**

## 备份与迁移

- 页脚「导出备份」：导出完整 JSON，可以原样导入恢复。
- 页脚「导入」：读取 JSON，按记录 id 合并去重，不会覆盖已有内容。

建议每个月导出一次，放到网盘或移动硬盘里。

## 云同步（可选）

如果想让手机和电脑自动同步，可以给自己的「随想」接一个 Supabase 项目（免费）。完整步骤见 [SYNC.md](SYNC.md)，大约 10 分钟。

配置写在 `assets/sync-config.js`：

```js
window.SUIXIANG_SUPABASE = {
  url: "https://你的项目.supabase.co",
  anonKey: "你的 anon public key"
};
```

留空时不显示登录入口、不发起任何网络请求，和纯本地版完全一样。

开启后：

- 顶栏出现「登录同步」，用邮箱和密码注册 / 登录；
- 登录后本机记录会与云端合并，之后新增、编辑、删除自动同步；
- 页脚会显示「已同步到云端」，同步失败时会有提示；
- 数据保存在**你自己的** Supabase 数据库里，每个账号只能读取自己的记录（RLS 保护）。

> `anon` key 可以公开，但**不要**填 `service_role` key。Supabase 是第三方服务，记录在数据库里是明文，不是端到端加密。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl / Cmd + K` | 聚焦搜索 |
| `Ctrl / Cmd + Enter` | 保存记录（编辑时保存修改） |
| `/` | 聚焦搜索（不在输入框时） |
| `Esc` | 取消编辑 / 清空搜索 / 退出搜索框 |

## 文件结构

```
journal/
├── index.html              页面结构
├── assets/
│   ├── app.css             样式（纯白、响应式）
│   ├── app.js              全部逻辑（无任何依赖）
│   └── sync-config.js      云同步配置，默认留空
├── supabase-schema.sql     云同步的建表语句
├── SYNC.md                 云同步设置步骤
└── README.md
```

没有构建步骤，也没有第三方库。想改字号、行宽或留白，直接改 `app.css` 顶部的变量和 `.shell` 的 `max-width` 即可。

## 常见问题

**换电脑怎么办？**
开了云同步的话，在新电脑打开同一网址、登录同一个账号即可。没开同步就在旧电脑导出 JSON，把 `journal` 文件夹和备份一起拷过去，打开后导入。

**能不能在手机上看？**
可以，页面适配了手机。用同一网址登录同一账号即可同步；手机浏览器的本地存储更容易被系统清理，建议开启云同步并定期导出。

**会不会上传？**
默认不会，页面没有任何网络请求。只有你填写 `sync-config.js` 并登录后，记录才会写入你自己的 Supabase 项目，作者看不到。

**为什么刷新后草稿还在？**
输入的内容会自动存为草稿，刷新或误关页面后可以接着写；点「丢弃」可清空。

**旧版本的记录还能用吗？**
能。读取时会保留旧数据里的心情、标签、收藏等字段，只是这个版本不再显示它们；搜索仍然会匹配标签。
